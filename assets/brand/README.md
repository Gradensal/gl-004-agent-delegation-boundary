# Gradensal Brand Asset

`gradensal-mark.png` is the approved Gradensal emblem used for this project.

## Usage

Use the supplied asset directly.

Do not:

- redraw the emblem
- regenerate the emblem
- reinterpret its geometry
- substitute a similar AI-generated mark
- distort its proportions
- recolor it into a different brand identity

## Visual Environment

The Gradensal visual system uses:

- black / near-black as the dominant environment
- luminous cyan
- aqua
- electric blue
- cobalt
- deep royal blue
- midnight blue
- restrained glow and dimensional lighting

Avoid:

- pink accents
- excessive neon
- generic AI-startup gradients
- bright blue backgrounds dominating the composition

The emblem should remain dimensional, premium, technical, and visually
consistent across Gradensal Lab, Signature Builds, GitHub, portfolio,
editorial, and social assets.
